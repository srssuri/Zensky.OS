Lightweight

Graphical installer
A Calamares installer to set up the system in a few clicks.

Installation

  1. Download the ISO and verify itCompare the SHA256 shown above with the one of your file.
  2. Create a bootable USB driveUse Ventoy, balenaEtcher or the dd command. Everything on the drive will be erased.
  3. Boot from the driveWhen the PC starts, open the boot menu (usually F12, F11, Esc or F8) and pick your USB drive.
  4. Try it, then installThe system starts in live mode. Run the installer whenever you want to put it on your disk.

Requirements

  • 64-bit processor (x86_64)
  • 2 GB of RAM minimum, 4 GB recommended
  • Graphics card with OpenGL ES 3.0 support
  • A USB drive of 4 GB or more

FAQ

Is MaDistro free?

Yes. It is free and its source code is public on GitHub.

Can I use Arch packages?

Yes. MaDistro is based on Arch, so you use pacman just like on Arch.

Can I try it in a virtual machine?

Yes, but turn on 3D acceleration in your VM settings. Hyprland needs it to start.

How do I report a bug?

Open an issue on the GitHub repository and include your hardware (processor, graphics card) and what happened.
